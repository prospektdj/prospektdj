# Skórki / Skins

## 🇵🇱 Polski

Skórka zmienia kolory tła, paneli, przycisków i obramowań. Wybierasz ją w **Ustawienia → Wygląd i wydajność → Skórka**.

| Skórka | Opis |
| --- | --- |
| Nowoczesna (domyślna) | Zaokrąglone rogi (3 px), grafitowe tło, karty kanałów w mikserze, pierścień postępu utworu. |
| Dracula | Fiolet i chłodne szarości w stylu palety Dracula. |
| Nord | Stonowany niebieski i szarości w stylu palety Nord. |
| Gruvbox Dark | Ciepłe brązy z żółtym akcentem w stylu Gruvbox Dark. |
| Tokyo Night | Granat z niebieskim akcentem w stylu Tokyo Night. |
| Carbon | Prawie czarne tła z pomarańczowym akcentem. |
| Midnight | Głęboki granat z turkusowym akcentem. |
| Neon | Ciemny fiolet z neonowym akcentem. |
| Oryginalna | Czarny wygląd z pierwszej wersji, z oryginalnym układem. Pasek nagłówka używa tych samych skróconych podpisów co pozostałe skórki. |

Wszystkie skórki nowoczesne mają tła tak ciemne jak w oryginalnej, czarnej wersji: tło deku jest prawie czarne, a panel bliski 8/255. Kolory palet są inspirowane znanymi motywami, nie są kopiami plików motywów.

## 🇬🇧 English

A skin changes the colors of backgrounds, panels, buttons and edges. Choose it in **Settings → Appearance and performance → Skin**.

| Skin | Description |
| --- | --- |
| Modern (default) | Rounded corners (3 px), graphite background, mixer channel cards, track progress ring. |
| Dracula | Purple accent and cool grays, inspired by the Dracula palette. |
| Nord | Muted blue and grays, inspired by the Nord palette. |
| Gruvbox Dark | Warm browns with a yellow accent, inspired by Gruvbox Dark. |
| Tokyo Night | Navy with a blue accent, inspired by Tokyo Night. |
| Carbon | Near-black backgrounds with an orange accent. |
| Midnight | Deep navy with a turquoise accent. |
| Neon | Dark purple with a neon accent. |
| Original | The black look of the first version, with the original layout. Its header uses the same short labels as the other skins. |

All modern skins have backgrounds as dark as the original black version: the deck background is nearly black and the panel is close to 8/255. The palettes are inspired by well-known themes; they are not copies of theme files.
