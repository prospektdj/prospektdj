# Bundled fonts

DejaVu Sans Bold is an open fallback for the logo, not Helvetica Neue. Noto Sans Devanagari, Bengali and Arabic are bundled for interface labels. ProspektChinese.otf is a renamed subset of Noto Sans CJK SC Regular containing the localized interface characters; it is not a complete CJK font. Original font license and copyright notices are included in this directory. No proprietary Helvetica font is redistributed.

Noto Emoji (monochrome variable outline font) is bundled under SIL OFL 1.1. Source: https://github.com/google/fonts/tree/main/ofl/notoemoji. Original copyright/license: NotoEmoji-OFL.txt. It is a fallback for plain text editing and characters outside the Twemoji atlas. Colored graphics, including supported joined sequences, are rendered separately from the font; see licenses/twemoji.
