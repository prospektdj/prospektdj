# Bundled fonts

## 🇵🇱 Polski

Dołączone fonty zachowują oryginalne licencje w tym folderze. Sedgwick Ave Display i Noto są na SIL OFL; Nimbus Sans na AGPL z wyjątkiem osadzania dokumentów. Helvetica, Arial i Segoe UI nie są redystrybuowane, tylko odczytywane z systemu użytkownika. DejaVu jest otwartym fontem awaryjnym. ProspektChinese to oznaczony podzbiór Noto CJK, nie pełny font chiński.

## 🇬🇧 English

DejaVu Sans Bold is an open fallback for the logo, not Helvetica Neue. Noto Sans Devanagari, Bengali and Arabic are bundled for interface labels. ProspektChinese.otf is a renamed subset of Noto Sans CJK SC Regular containing the localized interface characters; it is not a complete CJK font. Original font license and copyright notices are included in this directory. No proprietary Helvetica font is redistributed.

Noto Emoji (monochrome variable outline font) is bundled under SIL OFL 1.1. Source: https://github.com/google/fonts/tree/main/ofl/notoemoji. Original copyright/license: NotoEmoji-OFL.txt. It is a fallback for plain text editing and characters outside the Twemoji atlas. Colored graphics, including supported joined sequences, are rendered separately from the font; see licenses/twemoji.

Sedgwick Ave Display Regular (BANGER SITE heading): bundled unchanged from https://github.com/google/fonts/tree/main/ofl/sedgwickavedisplay . Copyright and SIL Open Font License 1.1: `SedgwickAveDisplay-OFL.txt`. Font embedded for offline use on all platforms.

Nimbus Sans Regular / Bold: https://github.com/ArtifexSoftware/urw-base35-fonts . Bundled unmodified under AGPL-3.0 with the document embedding exception in NimbusSans-LICENSE.txt; full text in NimbusSans-COPYING.txt. Source font files: https://github.com/ArtifexSoftware/urw-base35-fonts/tree/master/fonts . Used when the selected system font is unavailable. Helvetica is proprietary and is NOT redistributed; it is loaded only from the user's licensed system installation. Segoe UI and Arial are likewise system fonts.
