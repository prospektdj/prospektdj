# Twemoji — pre-alpha 0.0.1 test

## 🇵🇱 Polski

Kolorowe grafiki Twemoji są osadzone w pliku wykonywalnym i działają bez internetu. Zachowano nazwy Unicode i licencję CC BY 4.0. Pliki źródłowe: `assets/emoji`. `manifest.json` zawiera rozmiary i SHA-256 aktualnego zestawu. Licencje i autorzy: [informacje](../licenses/twemoji/README.md).

## 🇬🇧 English

Colored Twemoji graphics are embedded into the executable and work offline. Unicode filenames and the CC BY 4.0 license are preserved. Payload: `assets/emoji`. `manifest.json` records current sizes and SHA-256 hashes. Licenses and attribution: [notices](../licenses/twemoji/README.md).
