# Fonts — pre-alpha 0.0.1 test

## 🇵🇱 Polski

Fonty osadzone w programie. Helvetica, Arial i Segoe UI są odczytywane wyłącznie z legalnej instalacji systemowej; zastępczo używany jest Nimbus Sans. Pliki źródłowe: `assets/fonts`. `manifest.json` zawiera rozmiary i SHA-256 aktualnego zestawu. Licencje i autorzy: [informacje](../licenses/fonts/README.md).

## 🇬🇧 English

Embedded fonts. Helvetica, Arial and Segoe UI are loaded only from a licensed system installation; Nimbus Sans provides the fallback. Payload: `assets/fonts`. `manifest.json` records current sizes and SHA-256 hashes. Licenses and attribution: [notices](../licenses/fonts/README.md).
